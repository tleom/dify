# 模型调用的临时网络故障恢复

Agent 模型网关在首个响应块交付前，对连接失败、DNS 解析失败、超时、临时限流及服务暂不可用进行重试。首次调用失败后依次等待 2、4、8 秒，最多调用四次。文字、原生图片和工具执行后的模型续答共用这一入口。

重试仅重发当前模型请求，保留 Agent 运行、调用序号及追踪信息。每次尝试使用独立且可确定的调用标识，避免复用已释放的额度预留。鉴权和参数错误直接返回。消费端关闭生成器时同步关闭底层模型流。

模型已经交付响应块后不重新生成，以免重复输出或产生不同的工具调用。客户端与 Agent 的事件连接继续使用已有事件游标恢复。工具调用保留已有临时错误观察结果的处理，执行结果不确定的写操作不自动重放。

验证：隔离运行时中 API 132 项、Agent 27 项测试通过；其中新增 33 项覆盖立即失败和流首次读取失败、恢复、次数上限、永久错误、已交付内容及生成器关闭。故障由模型边界注入，没有在生产网络制造故障。完整上游 CI 未运行。

API 镜像：`dify-workbench-api:1.17.1-20260911.5`。
