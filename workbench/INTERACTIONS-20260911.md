# 停止、消息操作与思考设置更新记录

访问入口：<http://10.16.9.237:3100/>。本次改动已部署，刷新页面加载新版。

## 停止后继续发送

- 修复停止后历史中留有未返回的工具调用，导致下一条消息出现 400 的问题。使用 Dify Agent 所依赖的 Pydantic AI 原生 interrupted history 处理，保留先前真实输出并关闭中断调用，不重做被停止的工具。
- 原始错误事件中的 HTTP 状态码不再被当成任务状态。
- 取消尚未得到后台确认时显示“正在停止”，确认清理及执行名额释放后才恢复发送。确认期间也会阻止删除该会话，避免提前清理正在保存的上下文。

## 结果操作

- 每个已结束结果的左下方提供点赞、点踩、复制、重新生成。
- 点赞和点踩调用 Dify 的 `MessageService.create_feedback`，保存到原生 `MessageFeedback`；再次点击可取消，刷新后保留，账号之间隔离。
- 复制提取页面显示的回答文字，不混入折叠的工具参数和思考内容；同时支持 Clipboard API 与当前 HTTP 环境可用的浏览器复制命令。
- 重新生成通过原有队列与 Dify `AgentAppGenerator` 执行，传递原生 `parent_message_id`，恢复该问题生成前的上下文。保留原回答，在会话末尾新增一次结果；使用当前选择的模型与能力，原问题及附件路径保留，仍遵守既有并发限制。
- 新任务保存输入时的 history；早期历史任务根据原生消息的时间与用户输入定位上下文。历史数据无需批量改写。

## 思考选择与排版

- “文件”后增加“思考”入口，浮窗显示在输入框上方；切换选项自动保存到当前会话的 Dify 模型设置。
- 按当前模型的 Dify 参数规则显示可用项。当前 `qwen3.8-max` 为关闭、低 low、中 medium、极高 xhigh；`qwen3.8-flash` 为关闭、开启。支持 high 或 max 的模型才显示相应级别，不把 token 预算自行换算成强度等级。
- 去掉左上角 D 图标；标题在宽屏为 17px，中等宽度为 15px，调整左侧对齐及留白。
- 文件、思考、技能、插件、知识库之间统一为 3px，工具行上下外部间距实测均为 9px。手机窄屏允许工具栏分行，保留所有操作入口。
