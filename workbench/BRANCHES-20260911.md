# 问题编辑与回答版本

工作台复用 Dify 原生 `Message.parent_message_id` 和 Agent 生成通道。编辑问题与重新回答使用现有 `/workbench/runs/<id>/regenerate` 入口，新建任务与消息，保留原问题、原回答及后续分支。编辑文本时保留原附件。

新消息指定所选回答的 `parent_message_id`。服务端验证账号、租户、应用与会话归属，保存父任务关系及原生 Agent history 快照；切换分支后继续对话时恢复该版本的 history，保留工具调用和多模态记录。问题与回答分别显示版本按钮，浏览器按账号、工作空间和会话保存选择。

思考按钮显示开启状态或等级；顶部显示会话标题。原有网络重试和图标调整保留。

## 验证

- API 136 项、Agent 27 项测试通过；分支检查覆盖父消息归属、版本关系、history 保留及执行失败后的输入恢复。
- 前端 TypeScript、lint、生产构建与纯函数测试通过，lint 为 37 条已有警告。
- 真实模型六轮对话验证原问题及续问、编辑原问题及续问、重新生成旧回答、切回旧回答继续。实际模型输入没有混入另一分支；原生父消息正确，原消息保留，重复请求幂等，跨账号访问返回 404。
- Edge 验证取消编辑、保存并重新回答、问题/回答版本切换、刷新恢复选择。390px 手机视口中编辑框宽 336px，无横向溢出。
- OpenAPI 保持 15 条工作台路径，新增请求与响应字段已导出核对。数据库版本仍为 `wb20260911u171`。
